# 30명 동시 접속 예비 테스트 결과

**날짜** 2026-09-07 · **대상** https://mylecture-1-zeta.vercel.app (실제 배포, 실제 OpenAI) · **비용** 약 $2.7 (65장)

## 한 줄 결론

30명이 동시에 써도 **서버는 멀쩡합니다.** 실패·오류·타임아웃 0건. 유일한 실질 문제는
버그가 아니라 **OpenAI 분당 5장 한도 때문에 마지막 학생이 첫 그림을 최대 7분 40초 기다린다**는
것이고, 이건 설정으로 줄일 수 있습니다.

## 무엇을 어떻게 테스트했나

실제 교실을 그대로 흉내 내는 스크립트를 새로 만들었습니다 (`scripts/classroom-sim.ts`).
부하 테스트(`load-test.ts`)가 20건을 한 번에 던지고 한 프로세스에서 지켜보는 것과 달리, 이것은:

- 30대의 폰이 QR을 찍고 30초에 걸쳐 입장
- 각자 5단계 폼을 채우고 제출
- 대기 중 실제 앱과 **같은 간격(2.5초)**으로 상태 폴링 — 폴링마다 워커를 깨움
- 결과 화면이 실제 1MB 그림을 프록시로 미리 받음
- 60%가 갤러리로 이동해 ETag로 폴링
- 교사 노트북이 4초마다 대시보드 3개 경로 새로고침
- 각자 2장째까지 그림

전부 실제 프로덕션에 대고, 실제 API로 돌렸습니다. 30명 × 2장 = **60장**.

## 발견 (심각도 순)

### 1. [설정] 마지막 학생 대기 시간 — 유일한 실질 문제
FIFO + 5 IPM에서 마지막 학생은 첫 그림을 **최대 7분 40초** 기다립니다. 버그가 아니라 분당
한도의 산수입니다 (60장 ÷ 분당 4.6장 ≈ 13분, 거기에 입장 순번). 30명이면 문서가 가정한
20명보다 더 깁니다.

**대응 (효과 큰 순):**
- **실제 분당 한도부터 확인하세요.** 지금 `OPENAI_ADMIN_KEY`가 없어서 `pnpm check:limits`가
  실제 계정 한도를 못 읽고 있습니다 — 5 IPM은 **추정일 뿐 검증된 적이 없습니다.** 계정이
  Tier 2(20 IPM)라면 60장이 약 3분에 끝나고 이 문제가 통째로 사라집니다. Admin 키를 넣고
  한 번 돌려 보세요.
- 여전히 5 IPM이라면 수업 당일 교사 화면에서 순서를 **'모두 1장씩 먼저'**로 바꾸세요.
  마지막 학생 첫 그림이 약 7.7분 → 약 5분으로 당겨집니다 (전체 종료 시간은 동일).
- 또는 1인당 횟수를 처음엔 1장으로 두고, 시간이 남으면 2장을 여세요.

### 2. [정보] 응답이 느린 건 지역 탓, 오류는 아님
함수는 `iad1`(미국 워싱턴)에서 돌고 학생·Supabase는 멀리 있어, 제출은 3번의 OpenAI 호출
때문에 2.6~4.4초, 교사 대시보드는 1.7~2.7초(p99 3.9초) 걸립니다. 전부 폴링 간격 안에 들어가고
UI를 막지 않으며, 30명 부하에서도 **단 한 건도 실패하지 않았습니다.** Hobby는 단일 리전이라
지금은 바꿀 것 없습니다.

### 3. [정보] 용량·비용 여유 충분
그림 프록시 14.6MB, 갤러리 폴링의 62%가 304(ETag 정상 작동). 요청 약 7,100건 + 워커 호출은
Hobby 월 100만 호출·100GB 전송에 비하면 무시할 수준입니다. 한 달에 한 번 쓰는 앱이라 문제 없음.

### 4. [판단 필요 — 코드 아님] 이미 알려진 두 위험 재확인
- **Vercel Hobby 비상업 조항**: 위반 시 수업 중 503, 그날은 복구 불가. 걱정되면 Pro(월 $20).
- **Supabase Free 7일 일시정지**: keepalive cron이 막고 있고, 이번 점검에서 pg_cron 최근 응답이
  202(정상)였습니다.

## 다시 돌리는 법
```bash
# 로컬(무료, MOCK): 먼저 npx supabase start + pnpm build
pnpm tsx scripts/classroom-sim.ts --url http://127.0.0.1:3000 --n 30 --pictures 2 --teacher

# 프로덕션(실제 비용): TEACHER_PASSWORD 는 프로덕션 값으로
TEACHER_PASSWORD=... pnpm tsx scripts/classroom-sim.ts \
  --url https://mylecture-1-zeta.vercel.app --n 30 --pictures 1 --teacher --close
```
`--code XXXX`로 기존 세션에 붙거나, 생략하면 새 세션을 만듭니다. `--quality`, `--stagger`,
`--minutes` 옵션 있음. 리포트는 `out/classroom-sim/`에 JSON으로 남습니다.
